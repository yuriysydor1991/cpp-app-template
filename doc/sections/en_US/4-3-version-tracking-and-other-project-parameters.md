## Version tracking and other project parameters

The project's `meson.build` files are tracking the current project git repository commit, project name, configure date and project version that are forwarded into the project's configure header file located at `src/project-global-decls.h.meson.in`. The `project-global-decls.h.meson.in` will be compiled into the build directory as `project-global-decls.h` by the `configure_file()` call in `meson/template-project-configure-file/meson.build` during the project configure stage. The library sources include it whenever they need the project name, version, commit or configure date.
