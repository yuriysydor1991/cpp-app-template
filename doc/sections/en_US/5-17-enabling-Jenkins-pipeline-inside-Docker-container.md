## Running the Jenkins pipeline

The Meson flavors of the template ship no target which builds and starts a [Jenkins](https://www.jenkins.io/) container (the `jenkins-pipeline-docker-run` target is a part of the CMake flavors only), so the [misc/Jenkinsfile](/misc/Jenkinsfile) pipeline runs on a [Jenkins](https://www.jenkins.io/) instance of your own. Create a *Pipeline* job there with the *Pipeline script from SCM* definition, point it at the repository and the branch of the project and set its *Script Path* to `misc/Jenkinsfile`.

The agent running the job needs the tools the pipeline stages call: `git`, `meson` with `ninja-build`, `g++`, `pkg-config`, the GoogleTest / GoogleMock development packages, `clang-format`, `clang-tidy` and `cppcheck` - the [scripts/packages](/scripts/packages) install scripts install them - plus the tools of the packager stages its build parameters turn on: `rpm` for the `RUN_RPM_PACKAGER`, `flatpak-builder` for the `RUN_FLATPAK_PACKAGER`, `appimagetool` for the `RUN_APPIMAGE_PACKAGER` and `snapcraft` for the `RUN_SNAP_PACKAGER` one, while the `RUN_DEB_PACKAGER` one needs the `dpkg-deb` every Debian based system has. The `RUN_FREEBSD_PACKAGER` and the `RUN_WIX_PACKAGER` stages are FreeBSD and MS Windows only.
