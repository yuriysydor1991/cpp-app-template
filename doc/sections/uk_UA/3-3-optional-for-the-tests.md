## Необов'язкові пакети для тестів

Якщо необхідно побудувати і виконати доступні тести необхідно встановити пакети розробки GTest і GMock, які надають бібліотеки `gtest`, `gmock` і `gtest_main` разом з їхніми pkg-config файлами, які шукають скрипти Meson-побудови проекту-шаблону. Для встановлення системних пакетів необхідно виконати команду:

```
sudo apt install -y libgtest-dev libgmock-dev
```

Більш детально у секції [тести проекту](/doc/sections/uk_UA/4-4-project-tests.md).
