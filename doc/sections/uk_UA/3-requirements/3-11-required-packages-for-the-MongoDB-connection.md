## Обов'язкові пакети для підлкючення до MongoDB

Для того щоб зробити доступним драйвер MongoDB для C, на якому побудований драйвер для C++ проекту-шаблону, необхідно встановити його за допомогою наступної команди (ОС на базі GNU/Linux):

```
sudo apt install -y libmongoc-dev libbson-dev
```

Архіви більшості дистрибутивів взагалі не містять пакету драйвера MongoDB для C++, тому [модуль вмикання mongocxx](/doc/sections/uk_UA/5-project-build/5-37-enabling-the-mongocxx-library.md) самостійно завантажує та збирає цей драйвер, якщо у системі його немає. Наведені вище пакети драйвера для C є необов'язковими та звільняють завантажені вихідні коди від цієї частини побудови.
