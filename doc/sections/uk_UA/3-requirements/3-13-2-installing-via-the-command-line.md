### Встановлення за допомогою пакетного менеджера

Раніше Wt постачався пакунками `witty` і `witty-dev`, але жоден з випусків Ubuntu 24.04/26.04 чи Debian 13 їх більше не містить, тож там конфігурування проекту будує завантажений вихідний код Wt.

Скрипти `install-ubuntu-24-04.sh`, `install-ubuntu-26-04.sh` та `install-debian-13.sh` каталогу [scripts/packages](/scripts/packages) будують випуск Wt `4.11.4` з його вихідного коду та встановлюють його в систему так само, як це вручну робить підрозділ [Клонування і будування з вихідного джерельного коду](/doc/sections/uk_UA/3-requirements/3-13-1-cloning-and-building-from-sources.md), тож після цього конфігурування проекту знаходить встановлений Wt замість того, щоб його завантажувати.

FreeBSD постачає Wt портом `wt`:

```
sudo pkg install -y wt
```
