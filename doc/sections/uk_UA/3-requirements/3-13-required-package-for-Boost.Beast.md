## Обов'язкові пакети для Boost.Beast

Для того щоб зробити вбудований HTTP сервер Boost.Beast доступним у цільовій системі і для реалізованої програми відповідно, необхідно його встановити за допомогою наступної команди (ОС на базі GNU/Linux):

```
sudo apt install -y libboost-all-dev
```

Бібліотеки Beast та Asio складаються лише з заголовкових файлів, тож достатньо і пакунка `libboost-dev` лише з заголовками Boost, а зібраному виконуваному файлу для роботи пакунки Boost не потрібні.

### Параметри HTTP-сервера

Типово сервер слухає адресу `127.0.0.1:8080` і відповідає демонстраційною сторінкою на запити `GET` та `HEAD` шляху `/` (на запити `HEAD` - без тіла). Будь-який інший шлях отримує статус `404 Not Found`, а будь-який інший метод - статус `405 Method Not Allowed`. Змінні кешу CMake `PROJECT_HTTP_LISTEN_ADDRESS` та `PROJECT_HTTP_LISTEN_PORT` змінюють адресу та порт під час конфігурування, наприклад:

```
cmake -S . -B build -DPROJECT_HTTP_LISTEN_ADDRESS=0.0.0.0 -DPROJECT_HTTP_LISTEN_PORT=8000
```

Обмеження з'єднань та запитів описані в секції [Обмеження захисту HTTP-сервера](/doc/sections/uk_UA/5-project-build/security/5-50-the-HTTP-server-hardening-constraints.md). Під час очікування з'єднання сервер кожні 100 мс перевіряє прапорець зупинки застосунку, тож `Ctrl+C`, команда `kill` чи `docker stop` одразу його завершують.
