## Обов'язкові пакунки для SQLiteCpp

Проект-шаблон працює з рушієм баз даних [SQLite](https://www.sqlite.org/) через C++ обгортку [SQLiteCpp](https://github.com/SRombauts/SQLiteCpp). Встанови її пакунок для розробки наступною командою (ОС на базі GNU/Лінукс):

```
sudo apt install -y libsqlitecpp-dev
```

Якщо CMake не знаходить встановленої бібліотеки SQLiteCpp, то під час конфігурування проекту її сирці завантажуються з репозиторію `TEMPLATE_APP_SQLITECPP_GIT` за тегом `TEMPLATE_APP_SQLITECPP_GIT_TAG` (типово `https://github.com/SRombauts/SQLiteCpp.git` та `3.3.3`) і збираються разом з проектом, тож у такому разі потрібні система версіювання Git та з'єднання з Інтернетом. Обидві змінні кешу можна змінити під час конфігурування, наприклад:

```
cmake -S . -B build -DTEMPLATE_APP_SQLITECPP_GIT_TAG=3.3.3
```

Пакунок flatpak та образ Docker конвеєра Jenkins збирають SQLiteCpp з того самого репозиторію за тим самим тегом.

### Розташування файлу бази даних

SQLite не потребує сервера баз даних: виконуваний файл відкриває (і створює, якщо його немає) файл бази даних `<назва проекту><версія>.db` (наприклад, `CppAppTemplate0.11.0.db`) у директорії `$XDG_DATA_HOME/<назва проекту>` або в директорії `~/.local/share/<назва проекту>`, якщо змінну середовища `XDG_DATA_HOME` не задано. Відсутні директорії також створюються.

Щоб використати інший файл бази даних, задай змінну середовища `SQLITE_DB_PATH`:

```
SQLITE_DB_PATH=/path/to/the/database.db ./CppAppTemplate
```
