## Реалізуй код одразу!

Щоб одразу приступити до реалізації конкретної програми необхідно перейти до каталогу `src/qtdbus/query-handlers`: кожен запит D-Bus програми є класом, що реалізує інтерфейс `IDBusQueryHandler`, як-от клас `Hostname1QueryHandler`, який зчитує властивості служби systemd-hostnamed, а клас `DBusQueryHandlerFactory` створює обробник, який клас `QtDBusController` запускає через своє з'єднання з системною шиною.

**Але пам'ятаємо про принципи хорошого коду SOLID і його декомпозицію!**

Рекомендується додати новий нащадок `IDBusQueryHandler` для нового запиту та створити нові окремі директорії у проекті, котрі будуть розміщувати додаткові реалізовані компоненти програми, на противагу розміщенню усього коду всередині одного класу обробника.

Деякий додатковий код для Qt6 можна впроваджувати у клас `Qt6Initer`, який створює екземпляр `QCoreApplication`, потрібний модулю QtDBus.
