## Реалізуй код одразу!

Щоб одразу приступити до реалізації конкретної 3D програми необхідно перейти до файлу `src/SDL3/Painter/Painter.cpp` класу `Painter`, який призначений для утримання початкового коду малювання сцени. Більш точно новий код малювання OpenGL повинен бути розміщений у методі `bool Painter::paint(std::shared_ptr<SDL3Context> ctx)`, який цикл подій класу `SDL3Controller` викликає один раз на кадр. Події SDL3 обробляють нащадки класу `IEventHandler` у директорії `src/SDL3/Eventer/EventsHandlers`, яких клас `EventsHandlersFactory` обирає за типом події.

Вікно створюється з контекстом OpenGL 3.3 core profile, функції якого понад OpenGL 1.1 необхідно завантажити під час виконання: використай `SDL_GL_GetProcAddress` або бібліотеку-завантажувач (наприклад, [glad](https://github.com/Dav1dde/glad) чи [GLEW](https://glew.sourceforge.net/)) перед їх викликом.

**Але пам'ятаємо про принципи хорошого коду SOLID і його декомпозицію!**

Рекомендується створити нові окремі директорії у проекті, котрі будуть розміщувати додаткові реалізовані компоненти програми, і включити їх до реалізації класу `Painter`. На противагу розміщення усього коду тільки всередині класу `Painter` (для тривіального проекту це може бути виправданим).

Додатковий код може бути впроваджений у клас `Application` або за допомогою створення нащадка класу `IApplication`, щоб забезпечити варіативність на рівні виконуваного файлу.
