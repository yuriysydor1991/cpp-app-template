## Запуск конвеєра Jenkins

Meson-спеціалізації шаблону не мають цілі, яка будує та запускає контейнер [Jenkins](https://www.jenkins.io/) (ціль `jenkins-pipeline-docker-run` є лише у CMake-спеціалізаціях), отож конвеєр [misc/Jenkinsfile](/misc/Jenkinsfile) запускається на власному примірнику [Jenkins](https://www.jenkins.io/). Створи на ньому завдання типу *Pipeline* з визначенням *Pipeline script from SCM*, вкажи репозиторій та гілку проекту і встанови *Script Path* у значення `misc/Jenkinsfile`.

Агенту, що виконує завдання, потрібні інструменти, які викликають стадії конвеєра: `git`, `meson` разом з `ninja-build`, `g++`, `pkg-config`, пакети розробки GoogleTest / GoogleMock, `clang-format`, `clang-tidy` та `cppcheck` - їх встановлюють скрипти встановлення пакетів [scripts/packages](/scripts/packages), - а також інструменти стадій пакувальників, які вмикають його параметри побудови: `rpm` для `RUN_RPM_PACKAGER`, `flatpak-builder` для `RUN_FLATPAK_PACKAGER`, `appimagetool` для `RUN_APPIMAGE_PACKAGER` та `snapcraft` для `RUN_SNAP_PACKAGER`, тоді як `RUN_DEB_PACKAGER` потребує лише `dpkg-deb`, наявного на кожній системі на базі Debian. Стадії `RUN_FREEBSD_PACKAGER` та `RUN_WIX_PACKAGER` призначені лише для FreeBSD та MS Windows відповідно.
