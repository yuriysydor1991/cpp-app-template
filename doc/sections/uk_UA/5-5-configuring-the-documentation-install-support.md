## Вмикання підтримки встановлення документації

Наявна можливість підтримки встановлення документації за допомогою встановлення змінних `ENABLE_DOC_DOXYGEN` і `DOXYGEN_DO_INSTALL` у значення `true` під час конфігурування проекту-шаблону за допомогою команди:

```
# всередині кореневої директорії проекту

meson setup build -DENABLE_DOC_DOXYGEN=true -DDOXYGEN_DO_INSTALL=true
```

Після цього крок встановлення копіює згенеровану директорію HTML-документації у директорію `share/doc` префіксу встановлення (наприклад, `/usr/local/share/doc/CppAppTemplate-html`). Значення `DOXYGEN_OUT_HTML_NAME` у файлі `doc/meson.build` конфігурує назву директорії HTML-документації (передається до файлу `Doxyfile`).
