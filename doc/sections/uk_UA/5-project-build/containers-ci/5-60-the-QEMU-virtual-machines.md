## Віртуальні машини QEMU

Директорія [scripts/qemu](/scripts/qemu) містить сценарії запуску віртуальних машин FreeBSD та MS Windows за допомогою емулятора [QEMU](https://www.qemu.org/), тож гілки проекту збираються та перевіряються на цих системах просто з Linux хоста:

| Сценарій | Запускає |
| --- | --- |
| [freebsd.sh](/scripts/qemu/freebsd.sh) | машину FreeBSD з офіційного образу VM, який перший запуск завантажує та перевіряє |
| [windows.sh](/scripts/qemu/windows.sh) | машину MS Windows, яку перший запуск встановлює з вказаного інсталяційного ISO |

Хосту потрібні пакети `qemu-system-x86` та `qemu-utils`, а машині MS Windows також пакети `ovmf` (прошивка UEFI) та `swtpm` (TPM 2.0, якого вимагає MS Windows 11). Гостьова система працює з рідною швидкістю лише для користувача групи `kvm`, інакше процесор емулюється.

Кожна машина зберігається в директорії `~/.local/share/CppAppTemplate/qemu` і кожен запуск продовжує роботу з тим самим диском, тож все встановлене чи зібране в гостьовій системі в ній і залишається. Видалення директорії машини запускає її наново.

Аргументи сценаріїв передаються емулятору, наприклад аргумент `-vnc 127.0.0.1:1` показує екран гостьової системи через VNC замість вікна.

### FreeBSD

```
# всередині кореневої директорії проекту

scripts/qemu/freebsd.sh
```

Увійдіть як `root` без пароля. Репозиторій проекту хоста доступний гостьовій системі лише для читання, тож потрібна гілка за крок клонування:

```
# всередині гостьової FreeBSD

mount -t p9fs cpp-app-template /mnt
pkg install -y git
git config --global --add safe.directory /mnt
git clone -b app /mnt ~/cpp-app-template

cd ~/cpp-app-template
scripts/packages/install-freebsd.sh
scripts/build/release.sh
```

Порт SSH гостьової системи перенаправлено на порт `127.0.0.1:2222` хоста, який відповідає після того, як команда `sysrc sshd_enable=YES && service sshd start` увімкне SSH сервер гостьової системи, а команда `adduser` створить користувача для входу.

| Змінна | Типово | Значення |
| --- | --- | --- |
| `FREEBSD_VERSION` | `15.1` | випуск FreeBSD для завантаження та запуску |
| `FREEBSD_DISK_SIZE` | `64G` | розмір диска нової машини |
| `FREEBSD_SSH_PORT` | `2222` | порт хоста для SSH порту гостьової системи |

### MS Windows

MS Windows не має вільно доступного для завантаження образу диска, тож перший запуск приймає інсталяційний ISO з сайту Microsoft та запускає з нього встановлювач, а наступні запуски стартують встановлену систему:

```
# всередині кореневої директорії проекту

scripts/qemu/windows.sh ~/Downloads/Win11_English_x64.iso

scripts/qemu/windows.sh
```

Диск, мережева карта та вказівник машини є пристроями, драйвери яких містить встановлювач, тож жоден диск з драйверами не потрібен. Порт RDP гостьової системи перенаправлено на порт `127.0.0.1:13389` хоста, а порт SSH на `127.0.0.1:2223`.

Якщо на хості встановлено Samba `smbd`, то репозиторій проекту доступний як мережева папка `\\10.0.2.4\qemu`. Типово MS Windows 11 відмовляє в такому гостьовому доступі, який дозволяє PowerShell адміністратора гостьової системи:

```
Set-SmbClientConfiguration -RequireSecuritySignature $false -EnableInsecureGuestLogons $true
```

| Змінна | Типово | Значення |
| --- | --- | --- |
| `WINDOWS_VM` | `windows` | назва машини, яка дозволяє мати кілька встановлених систем поруч |
| `WINDOWS_DISK_SIZE` | `128G` | розмір диска нової машини |
| `WINDOWS_RDP_PORT` | `13389` | порт хоста для RDP порту гостьової системи |
| `WINDOWS_SSH_PORT` | `2223` | порт хоста для SSH порту гостьової системи |
| `WINDOWS_OVMF_CODE`, `WINDOWS_OVMF_VARS` | шляхи прошивки Debian, Ubuntu та Fedora | прошивка OVMF з підтримкою Secure Boot та шаблон її змінних |

### Спільні змінні

| Змінна | Типово | Значення |
| --- | --- | --- |
| `QEMU_VMS_DIR` | `~/.local/share/CppAppTemplate/qemu` | директорія машин та завантажень |
| `QEMU_MEMORY` | `8G` | розмір пам'яті гостьової системи |
| `QEMU_CPUS` | половина ядер хоста | ядра процесора гостьової системи |
| `QEMU_SYSTEM` | `qemu-system-x86_64` | емулятор для запуску |
