## Вмикання підтримки генерації flatpak пакету

Для того щоб увімкнути підтримку генерації пакету постачання flatpak на даному проекті-шаблоні необхідно сконфігурувати систему побудови з увімкненим параметром `ENABLE_FLATPAK` (для GNU/Linux подібних ОС):

```
# всередині кореневої директорії проекту 

mkdir -vp build && cd build && cmake ../ -DENABLE_FLATPAK=ON
```

Успішно виконана команда у свою чергу увімкне ціль для побудови під назвою `flatpak`.

Програма `flatpak-builder` збирає проект усередині власного оточення, котре не має доступу до мережі, тоді як вмикач Font Awesome звантажує свою робочу копію через Інтернет. Тому згенерований маніфест перелічує серед первинних кодів модуля те саме сховище `TEMPLATE_APP_FONTAWESOME_GIT` та ту саму мітку `TEMPLATE_APP_FONTAWESOME_GIT_TAG`, аби програма `flatpak-builder` звантажила робочу копію до входу в оточення, та передає її конфігуруванню всередині оточення через параметр `TEMPLATE_APP_FONTAWESOME_DIR`. Будь-яке інше джерело набору іконок (власне дзеркало сховища чи власна мітка) потрапляє до пакету flatpak тим самим шляхом: через ці дві змінні кешу.

На кінець, щоб згенерувати пакет розповсюдження flatpak необхідно побудувати ціль `flatpak`:

```
# всередині директорії побудови проекту-шаблону

cmake --build . --target flatpak
```

У разі успішної побудови цілі буде створено файл під назвою `CppAppTemplate-0.9.0-x86_64.flatpak` у кореневій директорії побудови проекту шаблону. Для того щоб преглянути або/і змінити ціль побудови пакету flatpak необхідно відвідати файли `cmake/template-project-flatpak-target.cmake` або `misc/packagers/flatpak/flatpak.conf.json.in`.

Необхідно звернутися до документації програми flatpak для того щоб дізнитись як встановлювати або запускати програми котрі розповсюджуються у вигляді пакету flatpak. Для не змінених паарметрів поточного проекту вони можуть виглядати наступним чином:

```
# для встановлення (версія може змінитись)
# всередині директорії побудови проекту-шаблону 
flatpak install --user CppAppTemplate-0.9.0-x86_64.flatpak

# для запуску встановленої програми
flatpak run ua.org.kytok.template.CppAppTemplate
```
