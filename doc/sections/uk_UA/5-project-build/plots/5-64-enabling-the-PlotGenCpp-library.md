## Вмикання інтеграції бібліотеки PlotGenCpp

Бібліотека [PlotGenCpp](https://github.com/skhelladi/PlotGenCpp) малює приклад графіка синусоїди цієї гілки у вікні [SFML](https://www.sfml-dev.org/). Обидві бібліотеки є обов'язковими для гілки і вмикаються CMake-змінними `ENABLE_PLOTGENCPP` та `ENABLE_SFML`, які за замовчуванням мають значення `ON`. Крок конфігурування CMake зупиняється з помилкою, якщо будь-якій з них встановлено значення `OFF`.

### Бібліотека PlotGenCpp

Бібліотека не постачає CMake-пакунку, тому вона завжди завантажується зі свого git-репозиторію під час кроку конфігурування CMake. Сам репозиторій та його теґ задаються CMake-змінними `TEMPLATE_APP_PLOTGENCPP_GIT` та `TEMPLATE_APP_PLOTGENCPP_GIT_TAG`:

```
# в середині кореневої директорії проекту

cmake -S . -B build -DTEMPLATE_APP_PLOTGENCPP_GIT_TAG=main
```

### Бібліотека SFML

Бібліотека PlotGenCpp та проект підключають бібліотеки `sfml-graphics`, `sfml-window` та `sfml-system` лінійки SFML 2. Встановлена у системі SFML 2 використовується, якщо її знайдено (пакунок `libsfml-dev` в Ubuntu 24.04 та Debian 13), інакше з git-репозиторію береться випуск `2.6.2` без модулів роботи зі звуком та мережею. Сам репозиторій та його теґ задаються CMake-змінними `TEMPLATE_APP_SFML_GIT` та `TEMPLATE_APP_SFML_GIT_TAG`.

Пакунок `libsfml-dev` в Ubuntu 26.04 містить SFML 3, яку пошук пропускає, тому там збирається завантажена копія. Для її збирання потрібні пакунки розробки X11, OpenGL, FreeType та udev:

```
sudo apt install -y libfreetype-dev libx11-dev libxrandr-dev libxcursor-dev libudev-dev libgl-dev
```

Скрипт [install-ubuntu-26-04.sh](/scripts/packages/install-ubuntu-26-04.sh) встановлює ці пакунки, а також збирає з вихідного коду та встановлює випуск SFML `2.6.2`, тож пошук і там знаходить встановлену у системі SFML 2.

### Встановлення

Бібліотека PlotGenCpp встановлює себе поруч із виконуваним файлом (разом зі своєю демонстрацією `PlotterExamples`), а завантажена SFML встановлюється до директорії `lib` префікса встановлення. На GNU/Linux встановлений виконуваний файл містить RPATH `$ORIGIN` та `$ORIGIN/../lib`, щоб знайти обидві, тож він запускається з будь-якого префікса встановлення та зі згенерованих пакунків.

### Запуск

Згенерований виконуваний файл відкриває вікно з графіком і завершується, щойно вікно закрито або натиснуто клавішу Escape:

```
./build/src/CppAppTemplate
```

Вікно та його цикл подій належать методу `PlotGen::show()` бібліотеки, який ніколи не перевіряє прапорець зупинки, що його встановлюють обробники сигналів програми, тому для завершення програми закрийте вікно.

### Структура підсистеми

Клас `plotgencppi::PlotGenCppController` з директорії `src/plotgencpp` малює графік, а клас `app::Application` керує ним. Тести замінюють бібліотеку замінником `src/plotgencpp/tests/mocks/plotgen/plotgen.h`, тому вони ніколи не відкривають вікна.
