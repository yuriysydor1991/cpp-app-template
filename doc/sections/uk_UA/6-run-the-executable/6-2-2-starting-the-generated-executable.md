### Запуск згенерованого виконуваного файлу

Якщо виконуваний бінарний файл скомпільований і наявний у директорії побудови проекту його можна запустити з терміналу використовуючи шлях знайдений з попередньої секції командою:

```
# наприклад, з директорії побудови

./src/CppAppTemplate
```

Виконуваний файл гілки `appDarknetXX` завантажує мережу YOLOv4-tiny (ваги якої завантажило конфігурування), виявляє об'єкти на зразку зображення darknetxx і записує у журнал кожен виявлений об'єкт: ім'я класу, ймовірність і прямокутник з лівого краю, верхнього краю, ширини і висоти у пікселях зображення. Власну мережу і зображення йому вказують параметри:

```
# з директорії побудови
./src/CppAppTemplate --cfg yolov4-tiny.cfg --dxxwjz1 yolov4-tiny.dxxwjz1 --names coco.names --image /шлях/до/зображення.jpg
```
