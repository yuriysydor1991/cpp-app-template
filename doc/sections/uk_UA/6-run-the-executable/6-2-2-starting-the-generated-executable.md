### Запуск згенерованого виконуваного файлу

Якщо виконуваний бінарний файл скомпільований і наявний у директорії побудови проекту його можна запустити з терміналу використовуючи шлях знайдений з попередньої секції командою:

```
# наприклад, з директорії побудови

./src/CppAppTemplate --docroot "_deps/wt-src;/resources" --http-listen 127.0.0.1:8000 --accesslog CppAppTemplate-http-access.log
```
 
Команда запустить Web-сервер побудованої [Wt](https://www.webtoolkit.eu/wt)-програми з реалізованою логікою Web-сайту котрий буде "слухати" запити на порт `8000` loopback мережевого інтерфейсу.

У разі необхідності очікування запитів з загального мережевого інтервейсу, себто ззовні локальної машини, необхідно замінити адресу `127.0.0.1` на `0.0.0.0`.

Значення параметра `--docroot` вказує на директорію, що містить директорію `resources` фреймворку [Wt](https://www.webtoolkit.eu/wt) з темами, таблицями стилів і зображеннями віджетів, а `/resources` після крапки з комою вказує Wt роздавати адреси під нею як статичні файли. Директорія `_deps/wt-src` містить вихідний код Wt, завантажений конфігуруванням проекту у директорію побудови. Встановлений у систему Wt зберігає директорію `resources` у директорії `share/Wt` свого префіксу встановлення, наприклад, `--docroot "/usr/local/share/Wt;/resources"`.

Виконуваний файл сам обробляє свої параметри `-h`/`--help`, `-v`/`--version` і `-l`/`--log-file <шлях>`, а усі інші передає серверу Wt. Щоб отримати детальний список параметрів командного рядка для виконуваного файлу побудованого разом з [Wt C++ фреймворком](https://www.webtoolkit.eu/wt) необхідно звернутись до його документації.

Для зупинки сервера необхідно натиснути `Ctrl+C` або надіслати процесу сигнал `SIGTERM`.
