# Встановлення

Для виконання встановлення необхідно виконати команди інсталяції всередині директорії побудови.

## Встановлення в директорію по замовчуванню

Для того щоб встановити побудовану бібліотеку разом з її файлами розробки у типовий префікс `/usr/local` необхідно виконати наступну команду у терміналі (для GNU/Linux):

```
# встановлює бібліотеку, наприклад, у /usr/local/lib/<multiarch>,
# а файли заголовків - у /usr/local/include
# виконати з кореневої директорії проекту

sudo meson install -C build
```

Бібліотека не є командою для запуску, отож змінювати `PATH` не потрібно: програма, зібрана з нею, знаходить її через динамічний завантажувач (після встановлення виконай `sudo ldconfig`, щоб оновити його кеш), а залежні проекти знаходять її через файли pkg-config та пакета CMake.

## Встановлення у директорію по вибору

Місце встановлення визначає префікс встановлення, обраний на етапі конфігурування (типово `/usr/local`). Для того щоб встановити бібліотеку під інший префікс, наприклад `/usr`, необхідно переконфігурувати директорію побудови з параметром `--prefix` і виконати встановлення, як показано вище:

```
# заміни шлях /usr власним за потреби
# виконувати з кореневої директорії

meson configure build --prefix=/usr
sudo meson install -C build
```

Префікс `/usr` розміщує бібліотеку у системній директорії бібліотек, у якій динамічний завантажувач шукає завжди. Будь-який інший шлях також може бути вказаний: тоді його необхідно передати змінною `PKG_CONFIG_PATH` або `CMAKE_PREFIX_PATH` до залежних проектів і змінною `LD_LIBRARY_PATH` (або через RPATH) до програм, зібраних з бібліотекою.

Параметр `--destdir` команди `meson install` не замінює префікс, а додає перед ним staging-директорію (команда `meson install -C build --destdir /tmp/stage` встановить виконуваний файл у директорію `/tmp/stage/usr/local/bin`), що і використовують цілі пакувальників.

## Встановлення документації

Якщо проект був сконфігурований для підтримки встановлення згенерованої документації командою, яка може виглядати наступним чином:

```
# з кореневої директорії

meson setup build -DENABLE_DOC_DOXYGEN=true -DDOXYGEN_DO_INSTALL=true
```

Команда інсталяції (наприклад, та яка показана у секції [Встановлення в директорію по замовчуванню](#встановлення-в-директорію-по-замовчуванню)) встановить згенеровану HTML документацію у відповідні директорії.
