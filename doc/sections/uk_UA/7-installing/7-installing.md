# Встановлення

Для виконання встановлення необхідно виконати команди інсталяції всередині директорії побудови.

## Встановлення в директорію по замовчуванню

Для того щоб встановити побудовану бібліотеку разом з її файлами розробки у типовий префікс `/usr/local` необхідно виконати наступну команду у терміналі (для GNU/Linux):

```
# встановлює бібліотеку, наприклад, у /usr/local/lib/,
# а файли заголовків - у /usr/local/include/CppAppTemplate-0.12
# виконати з директорії побудови проекту

sudo cmake --install .
```

Бібліотека потрапляє до директорії `<префікс>/${CMAKE_INSTALL_LIBDIR}`, а її заголовки та файли пакета CMake - поруч з нею, повну структуру дивись у секції [Встановлення файлів розробки бібліотеки](/doc/sections/uk_UA/5-project-build/5-37-installing-the-library-development-files.md). Бібліотека не є командою для запуску, отож змінювати `PATH` не потрібно; програма, зібрана з нею, знаходить її через динамічний завантажувач, який на більшості дистрибутивів GNU/Linux шукає у `/usr/local/lib` (після встановлення виконай `sudo ldconfig`, щоб оновити його кеш).

## Встановлення швидкими скриптами побудови

Скрипти секції [Швидкі скрипти побудови](/doc/sections/uk_UA/5-project-build/5-36-quick-build-scripts.md) виконують крок встановлення самостійно, коли вказано параметр `--install`, отож увесь цикл конфігурації, побудови і встановлення виконується однією командою:

```
# в середині кореневої директорії проекту

scripts/build/release.sh --install
```

Лише крок встановлення для вже побудованої директорії `build/release` виконує відповідний скрипт окремого кроку:

```
# в середині кореневої директорії проекту

scripts/build/release-install.sh --install
```

Обидва встановлюють у префікс `/usr` викликом `sudo cmake --install`, отож пароль `sudo` буде запитано. Без параметра `--install` крок встановлення повністю пропускається і пароль ніколи не запитується.

## Встановлення у директорію по вибору

Для того щоб встановити бібліотеку під інший префікс необхідно додати параметр `--prefix` до команди, яка показана вище, наприклад:

```
# заміни шлях /usr власним за потреби
# виконувати з директорії побудови проекту

sudo cmake --install . --prefix "/usr"
```

Префікс `/usr` розміщує бібліотеку у системній директорії бібліотек (наприклад `/usr/lib/x86_64-linux-gnu` на Debian та Ubuntu), у якій динамічний завантажувач шукає завжди. Будь-який інший шлях також може бути вказаний: тоді його необхідно передати змінною `CMAKE_PREFIX_PATH` до залежних CMake проектів і змінною `LD_LIBRARY_PATH` (або через RPATH) до програм, зібраних з бібліотекою.

## Встановлення документації

Якщо проект був сконфігурований для підтримки встановлення згенерованої документації командою, яка може виглядати наступним чином:

```
# з директорії побудови проекту

cmake ../ -DENABLE_DOC_DOXYGEN=ON -DDOXYGEN_DO_INSTALL=ON
```

Команда інсталяції (наприклад, та яка показана у секції [Встановлення в директорію по замовчуванню](#встановлення-в-директорію-по-замовчуванню)) встановить згенеровану HTML документацію у відповідні директорії.
