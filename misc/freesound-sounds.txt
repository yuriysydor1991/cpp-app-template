# The Freesound sounds this project makes available.
#
# Freesound publishes it's submissions under CC0, CC-BY and CC-BY-NC alike, one
# license per sound rather than one for the whole database, so every sound is
# named here together with the address it came from and the very license it was
# published under. Every line follows the
#
#   <category>/<file>|<download URL>|<license>|<file SHA-256>
#
# form, the '#' starting a comment and the empty lines being skipped. The
# category becomes the subdirectory the file is downloaded into and the first
# part of it's alias, the license and the source travel into the binary and
# are given back by the FreesoundSound::license and the
# FreesoundSound::sourceUrl accessors, while the SHA-256 checksum pins the very
# file the build accepts: a download carrying anything else stops the
# configure. Record the "sha256sum" output of a newly added file next to it.
#
# Keep this file the single place recording where a sound came from and what it
# is licensed under: the enabler refuses a sound file carrying no manifest
# entry, so the provenance can not silently go missing.
#
# The Freesound API needs an account token and the '/download/' address of a
# submission answers a logged in account alone - an anonymous request lands on
# the login page - so the publicly reachable preview address of every sound is
# recorded here instead:
#
#   https://cdn.freesound.org/previews/<first 3 digits of the id>/<id>_<uploader id>-hq.ogg
#
# The submission itself stays reachable as https://freesound.org/s/<id> and
# names it's uploader there, so the id inside the recorded address is the
# provenance of the very file. The sounds below are CC0 ones, so they need no
# attribution at all: a CC-BY submission added among them is to be credited by
# the application on it's own.
