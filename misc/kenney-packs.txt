# The Kenney sound packs this project makes available.
#
# Kenney publishes every pack under the CC0 terms. Every line follows the
#
#   <pack>|<archive URL>|<archive SHA-256>
#
# form, the '#' starting a comment and the empty lines being skipped. The pack
# name becomes the subdirectory the archive is unpacked into and the first part
# of every sound alias, while the SHA-256 checksum pins the very archive the
# build accepts: a download carrying anything else stops the configure instead
# of slipping different sounds into the binary.
#
# The archive address carries a content hash kenney.nl regenerates whenever a
# pack is updated, so an updated pack shows up as a failing download here. Take
# the new address from the pack's own page (https://kenney.nl/assets/<pack>),
# download the archive and record it's "sha256sum" output next to it.
